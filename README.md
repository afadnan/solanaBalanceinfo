#  📌 Solana Balance Checker
🔗 **Live Demo:** [Check your Solana Balance](https://solana-balance-checker-two.vercel.app/) <br />
A simple web application that allows users to check their Solana wallet balance and recent transactions using the Solana Blockchain and Alchemy API.




## 🚀 Features
✅ Check Solana wallet balance instantly <br />
✅ Fetch recent transaction history <br />
✅ User-friendly UI with a dark theme <br />
✅ Powered by React, Solana Web3.js, and Alchemy API <br />

## 🛠 Tech Stack
Frontend: React, JavaScript <br />
Blockchain: Solana Web3.js, Alchemy API <br />
Styling: CSS <br />

## 🔧 Installation & Setup
### 1️⃣ Clone the Repository <br />
git clone https://github.com/afadnan/solanaBalanceinfo.git <br />
cd solanaBalanceinfo <br />

### 2️⃣ Install Dependencies <br />
npm install <br />

### 3️⃣ Set Up Environment Variables <br />
Create a .env file in the root directory and add your Alchemy API key: <br />
REACT_APP_ALCHEMY_API_KEY=your_api_key_here <br />

### 4️⃣ Start the Development Server <br />
npm start <br />
This will run the app on http://localhost:3000/. <br />

## 🎯 Usage  
🔗 **Live App:** [Solana Balance Checker](https://solana-balance-checker-two.vercel.app/)  

1. Open the website.  
2. Enter your **Solana Wallet Address**.  
3. Click **"Check Balance"** to view your SOL balance and recent transactions.
